Reference Calibration Model

Monocular scale factor $S_{calib}$ is determined using known reference bounding box coordinates:

S_{calib} = H_{known} / || P_{top} - P_{bottom} ||_2

Target object points back-projected to 3D world coordinates:

X = (u - c_x) * Z / f_x
Y = (v - c_y) * Z / f_y
Z = Z_{metric} * S_{calib}
